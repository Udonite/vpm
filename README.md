# Udonite packages

The VRChat Creator Companion listing for [Udonite](https://github.com/Udonite/Udonite) and future packages.

Documentation: **[udonite.dajno.com](https://udonite.dajno.com)**

## Add to the Creator Companion

1. Open the Creator Companion and go to **Settings → Packages → Add Repository**.
2. Paste `https://udonite.github.io/vpm/index.json` and click **Add**.

Or press **Add to VCC** on the [listing page](https://udonite.github.io/vpm/).
